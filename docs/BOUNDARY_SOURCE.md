# India state boundary layer

Source: geoBoundaries gbOpen IND ADM1, boundary ID IND-ADM1-1811400.
Upstream: DataMeet India community / Election Commission of India.
License: Creative Commons Attribution 2.5 India (CC BY 2.5 IN).
License link: https://creativecommons.org/licenses/by/2.5/in/
Source metadata: https://www.geoboundaries.org/api/current/gbOpen/IND/ADM1/
Pinned download: https://media.githubusercontent.com/media/wmgeolab/geoBoundaries/9469f09/releaseData/gbOpen/IND/ADM1/geoBoundaries-IND-ADM1_simplified.geojson

Bundled file: public/india-states.geojson (upstream simplified geometry, unmodified).
At runtime the app adds normalized state IDs and computes padded camera extents.
Diacritics in names are normalized for matching, not used to change geometry.

The metadata lists boundaryYearRepresented=2011, buildDate=Dec 12 2023,
and 36 units. Features include Ladakh and the merged Dadra and Nagar Haveli
and Daman and Diu. These metadata dates do not certify current official accuracy.
This is a reference visualization, not a legal, cadastral or emergency-routing map.
The street basemap is a separate source and may depict boundaries differently.
